## 4. 测试集

测试数据应版本化、脱敏，并包含成功与边界样例：

### 文本

- 中文故事改写：短、中、长上下文。
- 分镜 JSON：字段完整、数组长度、角色一致性。
- 镜头参数：枚举、数值范围、异常输入。
- 超长、空输入、敏感数据和取消。

### 图像

- 多种画幅与尺寸。
- 单人/多人角色一致性。
- 场景、服饰、构图和文字元素。
- 固定 seed 重复性、非法尺寸和 OOM 边界。

### 图像编辑

- 参考图保持、局部修改、角色一致性。
- 缺失输入、错误格式和路径注入。

### 视频

- 短时长、不同运动强度、首帧约束。
- 帧间一致性、编码可播放性、取消与超时。

## 5. 指标定义

| 指标 | 定义 |
| --- | --- |
| 成功率 | 满足机器契约且产物可读取的任务比例 |
| 人工可用率 | 盲审后无需重生成即可进入下一阶段的比例 |
| P50/P95 延迟 | 从接受任务到终态；另记排队时间 |
| 首 token/首预览时间 | 用户可感知的首次进展时间 |
| 吞吐 | 固定并发下每小时完成量 |
| 峰值显存/内存 | 任务期间最大使用量 |
| 磁盘增量 | 模型缓存、临时文件和最终产物增量 |
| 结构化成功率 | 严格 schema 一次通过比例 |
| 重试率 | 完成一个可用产物所需额外尝试比例 |
| 本地单位成本 | 电力、折旧、存储和运维的估算 |

所有指标报告样本数、失败样例和测量方法。
