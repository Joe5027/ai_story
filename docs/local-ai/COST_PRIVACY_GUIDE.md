# 成本与隐私指南

> 核心原则：本地运行减少外部 API 费用和数据外发，但并非零成本，也不自动等于安全。电力、GPU、磁盘、运维、模型许可和人工审核都应计入总成本。

## 1. 当前边界

- 已有 Provider、Model、ProjectModelConfig 和 ModelUsageLog，可表达多 Provider、优先级、限流和使用记录。
- Provider/Vendor 的 `api_key` 与 RuntimeNode `access_token` 当前为普通数据库字符字段，存在明文密钥风险；不要把数据库备份、管理页截图或诊断输出当作可公开材料。
- 预算预留、统一工作项和 local-first 路由领域服务已实现；在迁移、接线和并发测试完成前，不能假定它们已经在运行环境阻止超支或数据外发。
- 默认付费预算为 `0`，语义是“禁止付费调用”，不是“不限额”。

## 2. 成本边界

### 本地成本

记录以下项目：

- GPU/CPU 购置与折旧。
- 电力与散热。
- 模型文件、缓存、输入输出和备份占用。
- 工作流维护、质量抽检、故障恢复和升级时间。
- 远程节点网络与托管费用。

### 付费 API 成本

按项目、阶段、Provider、模型、请求 ID 记录：预估成本、预留金额、实际金额、币种、释放金额和失败原因。当前实现使用六位小数 Decimal，禁止用二进制浮点金额。

预算规则详见 [../adr/0003-budget-reservation.md](../adr/0003-budget-reservation.md)。在完整链路验证前采用更保守控制：绑定 `hard_limit=0` 的策略，只在明确测试窗口临时启用单一 Provider，完成后立即关闭。

## 3. 付费调用安全线

所有付费调用必须同时满足：

1. `allow_cloud_data_transfer=true`，且授权人和授权时间已记录。
2. 当前数据分类允许发送到该 Provider。
3. Provider、模型、价格、汇率和地区策略已审核，且存在匹配本次用量的生效价目表。
4. `project_budget_cny`、全局每日预算和全局每月预算均为正数，预留成功。
5. 请求有幂等键，可追踪且不会被无限重试。

自动付费回退还必须满足：新路由已批准切流、项目 `allow_paid_fallback=true`，并且本地目标确实发生允许回退的技术/契约失败。主观质量或排队时间不属于技术失败。

用户显式“使用 API 重生成”不要求开启自动回退，但必须先做精确 Provider 估算，提交 `confirm_paid_generation=true`、`confirmed_max_cost_cny` 和 1–200 字符幂等键。完整流水线暂时不能可靠聚合最大费用；只要旧配置直接绑定 API Provider，`run_pipeline/` 会返回 `409 PAID_PIPELINE_CONFIRMATION_REQUIRED`，必须逐阶段估算与确认。

任何一项未知均应 fail closed。网络超时不得被解释为“可以绕过预算再试一次”。

## 4. 数据分类与路由

| 数据类别 | 默认路由 | 说明 |
| --- | --- | --- |
| 公开测试文本/合成素材 | 本地；经审批可付费 | 仍需检查许可证与内容政策 |
| 未发布故事、分镜、角色设定 | 本地 | 付费外发需项目所有者明确同意 |
| 用户上传、个人信息、商业秘密 | 本地且最小化 | 默认禁止第三方外发 |
| 密钥、令牌、数据库凭据 | 禁止进入模型 | 任何 Provider 均不得接收 |
| 违法或高风险内容 | 拦截/人工审核 | 本地模型也不能绕过合规要求 |

在日志、模型提示词和错误报告中尽量使用任务 ID、哈希和摘要，不复制完整用户素材。

## 5. 明文密钥风险

当前 Provider 密钥字段不是密钥保险库。最低控制要求：

- 数据库文件、备份和管理后台仅授权给必要人员。
- 日志中对请求头、URL 查询参数和 Provider 配置做脱敏。
- 不在 `.env.example`、Markdown、截图、终端共享记录中填真实密钥。
- 疑似泄露时先禁用 Provider、轮换密钥，再调查使用日志。
- 后续迁移到系统凭据库或加密字段时，保留双读迁移和可回滚方案，不在日志输出解密值。

## 6. 数据生命周期

为输入、提示词、输出、缩略图、临时工作流、日志和备份分别定义：用途、位置、访问者、保留期和删除审批。默认不长期保存完整提示词或外部响应体。

`E:\AI\ai-story-runtime` 不是天然的安全边界。建议：

- 将 `config`、`logs`、`workflows` 和 `artifacts` 分目录授权。
- 对远程节点使用独立服务账户。
- 备份前脱敏，恢复时进入隔离环境。
- 删除动作先列清单并由操作者确认，不用模糊通配符递归删除。

## 7. 成本核算表

每月可用以下公式：

```text
总成本 = 付费 API 实际金额
       + 本地节点电力
       + 硬件摊销
       + 存储和备份
       + 远程节点费用
       + 运维与质量审核工时
```

比较替代方案时同时报告成功率和质量，不用“单次生成成本更低”掩盖重复生成次数增加。

## 8. 审计与演练

至少验证：

- 预算为 `0` 时没有任何付费请求离开系统。
- 同一幂等键重复提交不会重复预留或扣费。
- 只有确认发生在外部提交前的安全失败才能释放预留；提交后的超时、取消或结果不明必须保留为 `manual_review`，人工确认未计费后才能释放。已发生外部消费则按真实 usage 结算，usage 缺失时按最坏预留额结算。
- 禁用付费回退与素材出站、预算归零后，旧 worker 或缓存配置不会继续外发。
- 日志、健康接口、错误包和备份中搜索不到真实密钥。

- [ ] 默认预算仍为 `0`，需要付费的项目有单独审批。
- [ ] 本地模型和工作流已用真实硬件完成基准，不以候选清单代替验证。
- [ ] Provider 密钥已限制访问，日志脱敏已验证。
- [ ] 预算、取消、超时、重试和恢复演练有证据。
- [ ] 负责人知道紧急开关和密钥轮换流程。
